# Tish's Kitchen order API

Orders from https://tishxkitchen.com land here instead of only in WhatsApp,
and show up in Tish's app at https://admin.tishxkitchen.com.
Cloudflare Worker + D1, the same setup as the A3D back office.

```
api.tishxkitchen.com/api/orders        the website posts orders here
api.tishxkitchen.com/api/menu          live menu, prices, sold out, delivery fee
api.tishxkitchen.com/api/admin/*       Tish's app, needs the admin key
```

## How an order flows

1. Customer presses **Send order to Tish**. The Worker checks it, prices it
   from its own menu (never the browser's numbers), saves it and answers with
   a code like `TK-7GG5`.
2. Tish's phone gets a notification (Web Push, straight from the Worker, no
   third party). Her app also checks for new orders every 30 seconds while open.
3. The order drops into her Orders list as unpaid, marked **Online**, with a
   **Confirm order on WhatsApp** button that messages the customer.
4. If the API cannot be reached, the website falls back to the old WhatsApp
   message, so an order is never lost.

When Tish edits the menu, prices, sold out or delivery fee in her app, the
website follows within a minute.

## Setup, once

1. Cloudflare: create an API token from the **Edit Cloudflare Workers**
   template and add **Account, D1, Edit**.
2. GitHub, this repo, Settings, Secrets and variables, Actions:
   `CLOUDFLARE_API_TOKEN` and `TISH_ADMIN_KEY` (32+ random characters).
3. Actions, **Deploy order API**, Run workflow. It tests, creates the D1
   database, deploys to `api.tishxkitchen.com` and sets the key.
4. In the customer site repo set `CONFIG.api` to `https://api.tishxkitchen.com/api`.
5. On Tish's phone open `https://admin.tishxkitchen.com/#key=<TISH_ADMIN_KEY>`
   once, then More, **Turn on notifications**. On iPhone the app has to be
   added to the Home Screen first and opened from there.

## Tests

```
npm install
node test.mjs
```

16 tests in Miniflare with a throwaway database, including decrypting a real
push message to prove the encryption.

## Deliberate choices

- Money in integer cents. Server sets prices; a stale or edited page cannot change them.
- Schema is created by the Worker on first use, so deploys never wait on a migration step.
- The VAPID key pair for notifications is generated by the Worker and kept in D1.
- No admin key configured means nobody gets in. Key compare is constant time.
- Max 8 orders per phone per 10 minutes, plus a hidden spam trap field.
